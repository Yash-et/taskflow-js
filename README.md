# TaskFlow : To-Do Manager

TaskFlow is a clean, responsive task management application built using HTML, CSS, and Vanilla JavaScript. It helps users organize daily tasks, track priorities, and monitor their progress through a simple dashboard.

## Features

- **Task Management:** Create, complete, uncomplete, and delete tasks.
- **Priority Management:** Organize tasks into High, Medium, and Low priorities.
- **Search:** Find tasks by title or description.
- **Filtering:** Filter tasks by All Tasks, Today, Important, and Completed.
- **Combined Filtering:** Combine search and priority filters.
- **Dashboard Statistics:** Track total, completed, and pending tasks.
- **LocalStorage Persistence:** Retain tasks across browser refreshes.
- **Empty States:** Helpful messages when no tasks match the filters or when the task list is empty.
- **Delete Confirmation:** Prevent accidental task deletion.
- **Randomized Backgrounds:** Enjoy a different pastel application background on page load.
- **Responsive Design:** Adapt to desktop, tablet, and mobile screens.
- **Accessibility Improvements:** Keyboard focus indicators and descriptive form controls.

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Browser LocalStorage

## Getting Started

1. Clone the repository:
   ```bash
   https://github.com/Yash-et/taskflow-js
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies or build tools are required.
